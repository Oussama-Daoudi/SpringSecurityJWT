# 🔐 Spring Security JWT Authentication API
A secure and scalable REST API for authentication and authorization using Spring Boot, Spring Security 6, and JSON Web Tokens (JWT). 
Features role-based access control for multiple entities (Students, Classroom, Club).

## ✨ Features

- 🔐 **JWT-based Authentication** - Stateless authentication with access & refresh tokens
- 🛡️ **Role-Based Authorization** - Multiple user roles (USER, ADMIN, STUDENT, TEACHER)
- 🔄 **Refresh Token Mechanism** - Secure token renewal without re-login
- 📦 **Modular Architecture** - Organized by entities (Students, Classroom, Club)
- 🔒 **Password Security** - BCrypt password encoding
- 🧪 **Comprehensive Testing** - Unit & integration tests
- 📄 **API Documentation** - Ready for Swagger/OpenAPI
